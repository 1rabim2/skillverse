## 🚀 How to Run the Project

### Quick Start (Already Running)

```bash
# Backend is running on:
# http://localhost:4000

# Frontend is running on:
# http://localhost:5174

# To use:
1. Open http://localhost:5174 in your browser
2. Register a new account
3. Complete email verification
4. Browse courses and enroll
5. Complete lessons and quizzes
6. View certificates and portfolio
7. Check leaderboard
8. Try language switcher (EN/ने)
```

### Restart if Needed

**Backend:**
```bash
cd backend
npm start
# Ctrl+C to stop
```

**Frontend:**
```bash
cd frontend
npm run dev
# Ctrl+C to stop
```
